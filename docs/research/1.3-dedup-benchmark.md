## Purpose

Provide a reproducible, inspectable harness to empirically design future Chinese Quote matching:

Real PGWhite Quote → Controlled Mutation → Candidate Quote

Precision over recall: false-positive merges are worse than leaving true duplicates.

---

## Methodology

1. **Seed extraction (optional, READ-ONLY SELECT once)**  
   `pnpm research:dedup:export-seeds` → `research/dedup-benchmark/fixtures/seeds.v1.json`  
   Subsequent runs need **no** DB access.

2. **Case generation (deterministic, in-memory)**  
   `pnpm research:dedup:generate` → `fixtures/cases.v1.json`

3. **Scoring + report**  
   `pnpm research:dedup:benchmark` → `output/benchmark-results.csv` + `benchmark-report.md`

4. **Dry-run matcher**  
   `pnpm research:dedup:dry-run -- --book 5 --chapter weread:13 --text "…"`

---

## Seed selection

Method id: `stratified_book_length_trait_v1`

- Fixed book allow-list spanning curated + Import #3 books  
- Per book: pick short / medium / long (prefer dialogue, multi-sentence, CN quotes)  
- Target 25–30 seeds; **not** first-N rows  
- Chapter: real WeRead `chapterUid` when joinable via ImportItem; else synthetic stable label

Details are recorded in `seeds.v1.json` → `selection_method`.

## Mutation taxonomy

| Family | Intent | Typical ground truth |
|--------|--------|----------------------|
| D1–D4 | Exact / whitespace / width / outer quotes | DUPLICATE |
| D5 | Punctuation tone risk | AMBIGUOUS |
| D6–D9 | Boundary expand/trunc | DUPLICATE |
| D10 | Sentence selection | DUPLICATE / AMBIGUOUS |
| D11–D13 | Edition-like edits | DUPLICATE / AMBIGUOUS |
| N1–N7 | Hard negatives | NOT_DUPLICATE |
| N8 | Containment trap | AMBIGUOUS |
| N9–N10 | Same text, different chapter/book | NOT_DUPLICATE |
| A1–A5 | Borderline | AMBIGUOUS |

Ground truth enum: `DUPLICATE` | `NOT_DUPLICATE` | `AMBIGUOUS`.

## Metrics (research normalize → score)

Implemented in-repo (no RapidFuzz/Python dependency):

| Feature | Why |
|---------|-----|
| `raw_exact` / `normalized_exact` | Baseline identity after NFC, width, whitespace, outer quotes |
| `full_similarity` | Normalized Levenshtein — whole-string edition noise |
| `partial_similarity` | Best-substring / boundary-shift resilience |
| `length_ratio` | Flags expansion/truncation vs rewrite |
| `containment` | Selection-boundary hypothesis |
| `jaro_winkler` | Short-line shared-prefix sensitivity |
| `char_bigram_dice` | Local character-order overlap |

Chinese punctuation is **not** aggressively stripped — we observe its effect.

## Safety / no-DB-write guarantee

## How to run

```bash
# One-time (needs .env DB_*):
pnpm research:dedup:export-seeds

# Offline thereafter:
pnpm research:dedup:generate
pnpm research:dedup:benchmark

# Dry-run:
pnpm research:dedup:dry-run -- --seed 1338 --text "候选文本"
pnpm research:dedup:dry-run -- --book 5 --chapter weread:13 --text "候选文本"
```
