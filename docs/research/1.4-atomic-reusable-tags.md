# PGWhite 1.4 — Atomic Reusable Tags (product principle)

**Date:** 2026-10-04  
**Status:** Authoritative product/retrieval principle for Annotation Workbench experiments from Prompt `zh-literary-atomic-v1.2` onward. Research Tag Library construction: see `docs/research/1.41-atomic-tag-library.md`.

## Principle

**Tag 不是一句话的解释，而是一个可反复组合的最小检索单元。**

Prefer **semantically atomic, reusable retrieval concepts** over quote-specific literary descriptions, summaries, or compound interpretations.

PGWhite tags should **not** primarily demonstrate how well a model can summarize or interpret a Quote.

A tag should behave like a **reusable semantic component** that can recur across many Quotes and compose with other tags.

## High granularity ≠ many highly specific tags

High granularity means each individual tag is a **small reusable component**.

It does **not** mean generating many highly specific compound labels.

| Prefer (atomic reusable) | Avoid (quote-specific / compound summary) |
|--------------------------|---------------------------------------------|
| 童年 + 记忆 | 童年回忆 |
| 记忆 | 记忆与损伤 / 记忆的损伤 |
| 音乐 + 记忆 | 音乐唤醒记忆 |
| 死亡 + 恐惧 | 对死亡的恐惧 |
| 遗憾 | 持久性的遗憾 |
| 体谅 | 关系中的体谅 |

A user researching **记忆** should not need to guess: 记忆损伤、记忆唤起、童年回忆、旧日空间召回、记忆扭曲…

Searching the foundational concept should eventually retrieve Quotes discussing different properties, conditions, or transformations of that concept.

This supports PGWhite as an **exploratory library**, not an enumeration-of-evidence system.

## Atomic ≠ mechanical word splitting

Do **not** implement “shorter is always better.”

Do **not** mechanically split every multi-word phrase.

Stable multi-word semantic units may remain intact, e.g.:

- 身份认同
- 情感寄托
- 存在主义

**Test:** Can this concept naturally recur across many Quotes without encoding this Quote’s specific event, causal structure, object, or wording?

## Separate interpretation from tag naming

Strong literary understanding remains desirable.

Workflow:

```text
strong literary understanding
  → identify underlying semantic components
  → output simple reusable tags
```

Sophisticated reasoning may stay internal. Output vocabulary should be restrained.

## Workbench human-review framing

Keep:

1. Would I search for this Quote using this tag?

Add:

2. If a user only knows the foundational concept they want to explore, can they naturally retrieve this Quote without guessing a highly specific compound tag?

Do **not** collapse evaluation into a single accuracy score. Legacy human tags remain weak references only.
