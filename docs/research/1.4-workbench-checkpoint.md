## Prompt + schemas

- Prompt version: **`zh-literary-rich-v1`**
- Soft richness: Theme usually 3–5; Device usually 0–3; fewer/zero/more allowed; no filler
- LLM never sees canonical taxonomy during free generation
- Personal Annotation = evidence; patterns: `tag_signal` | `reflective_note` | `mixed` | `unclear`
- Character-like signals recorded under annotation interpretation only
- Original annotation is preserved by the Workbench/fixture input layer — **not** echoed by the LLM (`original_annotation_unchanged` removed from LLM schema)

## Experiment / run metadata

Schema: `experiment-run.v1`  
Immutable per `run_id`. Fields include free concepts, reconcile candidates + similarities, `existing_assignment` | `new_personal_concept`, annotation interpretation, weak human-reference overlap, human evals (per-run only), aggregates.

Default first-live design recommendation: `reconcile_threshold: null` (record candidates; do not auto-assign) until human review calibrates behavior.

## Embedding comparison plan (BGE-M3 vs Qwen3-Embedding)

**Goal:** compare reconciliation *behavior* and taxonomy-gap discovery — **not** “who has higher similarity.”

### Shared inputs (held constant)

1. Same fixture `annotation-bench-v1`
2. Same free-concept stage outputs (one LLM run → frozen `free_concepts` artifact)
3. Same taxonomy `reconcileTargets` (Theme w/o 时间 + Device)
4. Same prompt version for the free-concept stage

### Vary

| `run_id` pattern | Embedding |
|------------------|-----------|
| `…-reconcile-bge-m3` | BGE-M3 / FlagEmbedding-family |
| `…-reconcile-qwen3` | Qwen3-Embedding |

Optional: `reconcile_threshold` sweeps later — not required for first comparison.

### Primary measurements (no single accuracy)

1. Free Theme / Device concepts per Quote (from shared LLM stage)
2. Fraction of concepts with a *plausible* Existing Assignment under human review
3. New Personal Concept rate
4. Rate of **bad taxonomy match** flags when auto-assign is enabled (or when reviewers judge top-1)
5. Recurring Personal concepts / concepts with no canonical home
6. Annotation vs no-annotation differences in free-concept usefulness
7. Weak human-reference overlap (label only — not accuracy)
8. Qualitative: does either embedder systematically force 比喻→隐喻-style collapses?

Similarity distributions may be logged as secondary diagnostics only.

## Research evaluation emphasis

Do **not** optimize for embedding similarity or reconciliation rate.

First-order questions:

1. What free Chinese literary concepts appear?  
2. How many are genuinely in taxonomy?  
3. How many should stay Personal?  
4. Where does reconcile invent bad mappings due to sparse taxonomy?  
5. Does taxonomy constrain interpretation undesirably?  
6. Does Personal Annotation help?  
7. What systematic gaps recur?
