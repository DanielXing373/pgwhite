- 1.41 Atomic Tag Library loader (active Themes only; 217)
- Representations A/B/C (exact 1.41 semantics)
- Deterministic canonical/alias substring evidence (separate from embeddings)
- Embedding provider boundary + deterministic fake provider
- Cosine ranking with Top-5/10/20 reporting
- Benchmark schema + synthetic smoke fixture (not calibration GT)
- Recall@K evaluation
- Immutable run artifacts with overwrite protection
