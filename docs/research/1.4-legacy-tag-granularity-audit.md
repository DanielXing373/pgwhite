# Legacy Chinese human-tagged granularity audit (40 Quotes)

**Fixture:** `annotation-bench-v1.1` · group `legacy_human_tagged` · n=40  
**Role:** weak references only — **not ground truth**

## Unique tags observed in the 40

### Theme (already mostly atomic)

记忆, 寂静, 焦虑, 轮回, 敏感, 命运, 末日, 时间, 衰败, 死亡, 痛苦, 厌恶, 掌控

These generally behave like **atomic reusable components**. They demonstrate useful PGWhite-style Theme granularity.

Caveats:
- **时间** is atomic in form, but product-excluded from Workbench reconcile due to Scene/Time conflict — do **not** use as a generation few-shot target for active Theme teaching in v1.2.
- Coverage is sparse (many themes appear on only 1 Quote).

### Device

| Tag | Assessment |
|-----|------------|
| 拟人, 通感, 意象 | Reusable conventional device terms — good PGWhite-style |
| 隐喻 | Reusable term, but **over-applied** (22/40 Quotes) — weak teaching signal |
| 外貌描写, 动作描写, 长句描写 | Craft labels; somewhat descriptive; reusable but not classical 修辞格 |
| 内涵 | Overly broad / vague — poor teaching example |

### Scene/Time (present on some Quotes)

黄昏, 正午(n/a in 40), 深夜, 日出, 暴风雨 — atomic-ish, but **not** an active generation dimension in 1.4 v1 experiments.

## Suitability for teaching Atomic Tags

| Suitable as behavioral demos? | Why |
|-------------------------------|-----|
| **Partially yes for Theme** | Historical Theme labels are already short reusable nouns (记忆/死亡/焦虑/痛苦/寂静/衰败…) |
| **Weak for Device pedagogy** | Extreme 隐喻 dominance + vague 内涵 |
| **Not a full few-shot curriculum** | Only 17/40 Quotes have any Theme; almost no positive examples of “decompose compound → atomic components” because legacy tags rarely look like compound summaries |

Conclusion: the old dataset can illustrate **desired Theme atomicity**, but it does **not** contain enough “BAD compound → PREFER atomic split” cases. Decomposition behavior must be taught with **conceptual** BAD/PREFER examples, not forced historical few-shots.
